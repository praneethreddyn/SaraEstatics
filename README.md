# 💎 SaraA Estatics

A modern and responsive **jewelry e-commerce website** designed to showcase and sell elegant jewelry products such as **chains, bracelets, pendants, and rings**.

The project focuses on creating a clean, attractive, and user-friendly shopping experience with responsive product displays, intuitive navigation, and a simple ordering workflow.

## 🌐 Live Demo

**Website:**  
https://praneethreddyn.github.io/SaraA_Estatics/

## 📌 Project Overview

**SaraA Estatics** is a static e-commerce website developed for a jewelry brand. It provides customers with an easy way to browse jewelry products, view product information, and proceed toward placing an order.

The website is designed with a responsive layout so that it can be accessed comfortably from desktops, tablets, and mobile devices.

## ✨ Features

- 💍 Jewelry product showcase
- 🔗 Chains, bracelets, pendants, rings, and other products
- 📱 Responsive design
- 🛍️ Product browsing interface
- 📦 Product information stored using JSON
- 🔎 Dynamic product handling using JavaScript
- 📝 Order page for customer orders
- 🧭 Simple and intuitive navigation
- 🎨 Clean and modern user interface
- ⚡ Lightweight static website
- 🌐 Deployable using GitHub Pages

## 🛒 Product Data

Product information is maintained separately in `products.json`.

This approach makes it easier to add, remove, or modify products without having to redesign the complete webpage.

Example product information can include:

```json
{
  "name": "Elegant Gold Chain",
  "category": "Chains",
  "price": "₹XX,XXX",
  "image": "product-image.jpg"
}
```

## 🚀 Getting Started

Since this is a static website, no backend server or database is required.

### 1. Clone the repository

```bash
  git clone https://github.com/praneethreddyn/SaraA_Estatics.git
```

### 2. Open the project

```bash
cd SaraA_Estatics
```

### 3. Run the website

You can simply open:

```text
index.html
```

in a web browser.

For development, you can also use **VS Code Live Server** or another local HTTP server.
